# Revise — parcours de révision

Site statique francophone pour réviser les **bases de données** à travers des exercices pratiques SQL et la **création et gestion d’entreprise**.

## Utilisation

Ouvrir `index.html` dans un navigateur ou publier le dossier sur un hébergement statique. Aucun framework, installation ni compilation n’est nécessaire.

## Parcours

- **Bases de données** : rappel des étapes de création et de remplissage des tables, premier quiz sur le TP de gestion commerciale, exercices progressifs, leçons, QCM théoriques et glossaire.
- **Création & gestion d’entreprise** : cinq chapitres, explications développées, formules et QCM commentés.
- Points, validation d’activités, brouillons et progression sauvegardée localement.

## Progression

La progression est conservée dans le navigateur. Aucune donnée de progression n’est envoyée à un serveur. La sauvegarde dépend des capacités du navigateur et peut être limitée en ouverture directe du fichier ; un hébergement HTTPS permet une expérience plus fiable.

Les activités SQL sont corrigées par vérification des éléments attendus dans la réponse. Le site n’exécute pas directement les requêtes dans Oracle.
