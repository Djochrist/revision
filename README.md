# Revise

Site statique de révision avec deux parcours : Bases de données et Création & gestion d’entreprise.

## Lancer localement
Ouvrir `index.html` dans un navigateur moderne.

## Publier
Publier le fichier `index.html` sur un hébergement statique. Aucun serveur ni installation n’est nécessaire.

## Contenu
- Bases de données : algèbre relationnelle, assertions Oui/Non, QCM SQL, leçons et glossaire.
- Création & gestion d’entreprise : cinq chapitres et QCM commentés.
- Scores et progression conservés localement dans le navigateur.

Les activités sont proposées sous forme de choix multiples ; aucun éditeur de saisie de requêtes n’est nécessaire.
